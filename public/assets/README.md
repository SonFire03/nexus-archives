# Assets NEXUS

Ce dossier reçoit uniquement les médias locaux validés pour publication. Tous les fichiers d’un dépôt public sont accessibles à tous : ne placez ici aucun secret ni document privé.

## Emplacements et noms recommandés

- `images/operator-a7-portrait.webp` : portrait final d’A7 ;
- `images/operator-crimson-portrait.webp` : portrait final de Crimson ;
- `images/armor-{id}.webp` : visuel d’armure, par exemple `armor-ombre.webp` ;
- `images/faction-{id}.svg` : symbole original de faction ;
- `images/vanta-map-hires.webp` : carte détaillée optionnelle ;
- `images/nexus-logo.svg` : identité finale originale ;
- `audio/transmission-{id}.ogg` : transmission localisée ;
- `audio/ambient-terminal.ogg` : ambiance discrète en boucle.

Compresser les images, fournir des dimensions explicites et conserver une alternative textuelle. Les sons doivent être courts, optimisés et ne jamais démarrer sans consentement. Aucun asset distant ou protégé ne doit être copié.
