# Assets NEXUS

Ce dossier reçoit uniquement les médias locaux validés pour publication. Tous les fichiers d’un dépôt public sont accessibles à tous : ne placez ici aucun secret ni document privé.

- `images/brand/` : logo et symbole NEXUS ;
- `images/operators/` : portraits A7 et Crimson ;
- `images/armors/armor-{id}.webp` : les 18 châssis ;
- `images/factions/faction-{id}.webp` : les huit emblèmes ;

- `images/crimson-surveillance.webp` : portrait de surveillance de Crimson ;

- `images/armor-ombre-restoration.webp` : armure après restauration ;
- `images/zero-evacuation-tunnel.svg` : carte du tunnel d’évacuation ;
- `audio/transmission-{id}.ogg` : transmission localisée ;
- `audio/ambient-terminal.ogg` : ambiance discrète en boucle.

Les WebP publiés sont générés depuis les PNG haute résolution conservés localement dans `assets-source/images/`, dossier ignoré par Git. Les noms doivent rester en kebab-case, sans espace ni accent. Fournir des dimensions explicites et une alternative textuelle. Les sons doivent être courts, optimisés et ne jamais démarrer sans consentement. Aucun asset distant ou protégé ne doit être copié.
